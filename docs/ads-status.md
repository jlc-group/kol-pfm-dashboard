# สถานะการยิงแอดบนหน้า Ads

12 ต.ค. 2026 ผู้ใช้สั่งให้คอลัมน์ "หลักฐานการเริ่มยิง" และ "ความตรงเวลาเริ่มยิง" (ที่เพิ่มเมื่อ 7 ต.ค.) กลับเป็นแบบเดิมทุกอย่าง:

- **สถานะ**: ปุ่ม **✓ ยิงแล้ว / ยังไม่ยิง** กดทีเดียว ไม่มีหน้าต่างยืนยัน
  - กด "ยังไม่ยิง" → ยิงแล้ว และลงวันยิงแอด (`ad_end`) เป็นวันนี้ — ถ้ามีวันยิงแอดอยู่แล้ว (เช่น PFM ลงวันแรกที่มีค่าแอดให้) ใช้วันนั้นต่อ
  - กด "✓ ยิงแล้ว" → ยังไม่ยิง และล้างวันยิงแอด
  - มีค่าแอดแล้วแต่ทีมยังไม่กด = ขึ้น "✓ ยิงแล้ว **จากค่าแอด**" (สีอ่อน · ไม่เขียนลงฐาน กดเพื่อยืนยันได้)
  - TikTok ของแบรนด์ที่ต่อ PFM (Beauterry / Jarvit / Jernis) = ป้ายอ่านอย่างเดียว "อัตโนมัติ (PFM)" กดเองไม่ได้
  - แท็บไม่ต้องยิงแอด = ป้าย "ไม่ต้องยิง ไม่ใช้ Gencode"
- **ระยะเวลายิง**: **ตรงเวลา** (ยิงภายใน 3 วันนับจากวันที่ข้อมูลพร้อมยิง) · **ช้า N วัน** · ยังไม่ยิง = —
  - นับจากวันที่ข้อมูลครบชิ้นสุดท้าย (ลงคลิป / ใส่ Gencode / ใส่ ID Post / ทีมอนุมัติ) ถึงวันยิงแอด (`client/src/data/adTiming.js`)
  - ยิงก่อนวันที่ข้อมูลพร้อม (รวมยิงก่อนวันลงโพสต์) = ตรงเวลา — ผู้ใช้เลือกแบบเดิม ไม่มีป้าย "ต้องตรวจวันที่"
- ยอดเงินยังปิดตามสิทธิ์เดิม; `ad_has_spend` บอกเพียงว่ามีค่าแอด ไม่เปิดเผยจำนวนเงินแก่ member

การปรับนี้ไม่เปลี่ยนสูตร PFM/Stamp, วิธีจับคู่ข้อมูล หรือระบบ Beauterry/WeBoostX · `client/src/components/AdConfirmationModal.jsx` ไม่ถูกใช้แล้ว
