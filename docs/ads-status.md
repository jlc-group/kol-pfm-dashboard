# สถานะการเริ่มยิงบนหน้า Ads

- **มีค่าแอดแล้ว**: มีค่าแอดสะสมมากกว่าศูนย์ เป็นหลักฐานว่าเคยยิง ไม่ใช่สถานะเปิด/หยุดปัจจุบัน
- **ทีมยืนยันว่าเริ่มยิงแล้ว / PFM แจ้งว่าเริ่มยิงแล้ว**: มีสถานะเริ่มยิงในระบบ แต่ยังไม่มีค่าแอดสะสมยืนยัน
- **ยังไม่มีข้อมูลว่าเริ่มยิง**: ยังไม่มีค่าแอดหรือสถานะเริ่มยิง ไม่ใช่ข้อสรุปว่าไม่มีโฆษณาอยู่บนแพลตฟอร์ม
- ป้ายเป็นข้อมูลอ่านอย่างเดียว; โพสต์ที่แก้มือได้มีปุ่ม **แจ้งการเริ่มยิง / แก้การยืนยัน** แยกต่างหาก
- ฟอร์มให้เลือกวันเริ่มยิงจริง ไม่ลงวันปัจจุบันให้เอง ไม่ได้สั่งเปิด/ปิดแอดในแพลตฟอร์ม ยกเลิกการยืนยันขณะที่มีค่าแอดจะยังแสดงหลักฐานค่าแอด และคงวันที่ที่บันทึกไว้
- สถานะอัตโนมัติของ TikTok ที่เชื่อม PFM ยังแก้มือไม่ได้ตามสิทธิ์และกฎเดิม
- **ความตรงเวลาเริ่มยิง** นับจากวันข้อมูลพร้อมยิงถึงวันเริ่มยิง เกณฑ์เดิม 3 วัน ไม่ใช่ระยะเวลาที่แอดเปิด
- **ต้องตรวจวันที่** แสดงวันเริ่มยิงที่ก่อนวันลงโพสต์ พร้อมลิงก์ไปแคมเปญ ไม่เดาหรือแก้วันที่ในฐานข้อมูลเอง
- ยอดเงินยังปิดตามสิทธิ์เดิม; `ad_has_spend` บอกเพียงว่ามีค่าแอด ไม่เปิดเผยจำนวนเงินแก่ member

การปรับนี้ไม่เปลี่ยนสูตร PFM/Stamp, วิธีจับคู่ข้อมูล, วันเริ่มยิงเดิม หรือระบบ Beauterry/WeBoostX
